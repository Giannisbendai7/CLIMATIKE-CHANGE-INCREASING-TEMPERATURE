### CLIMATI-CHANGE-INCREASING-TEMPERATURE 

This project focuses on analyzing global temperature data to study climate change trends over time.

The goal is to identify patterns in temperature increase, explore long-term climate behavior, and visualize global warming trends using data-driven methods.

The project includes data cleaning, exploratory data analysis (EDA), and visualization techniques to understand temperature variations across different time periods and regions.

Tech stack: Python, Pandas, NumPy, Matplotlib, Seaborn

Key steps:

Data collection and preprocessing
Time-series analysis of temperature data
Exploratory data analysis (EDA)
Data visualization of climate trends
Interpretation of global temperature changes
